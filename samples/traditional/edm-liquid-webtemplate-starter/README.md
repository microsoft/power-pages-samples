# EDM Liquid Web Template Starter (placeholder)

> **Status: planned — this is a placeholder.** The sample is not implemented yet.
> This folder reserves the location and describes what the sample will teach.

## What this sample will show

A minimal **traditional Power Pages site** (not a code site) built on the
**enhanced data model (EDM)** that renders Dataverse data with **Liquid** and a
**web template**:

- One web template + page template that lists rows from a single Dataverse table.
- Basic list and form rendering with Liquid (no custom framework, no SPA).
- Site metadata authored declaratively (`modelVersion: 2`).

It is the entry point for the "traditional / non-code sites" category — the
Liquid + web template counterpart to the code-site (SPA) samples under
[`../../spa/`](../../spa/).

## Why it lives under `traditional/`

`traditional/` holds sites that use the classic Power Pages rendering stack
(Liquid, web templates, lists, and basic forms) rather than a bundled
JavaScript app. See the repository [README](../../../README.md) for how the
sample categories relate.
