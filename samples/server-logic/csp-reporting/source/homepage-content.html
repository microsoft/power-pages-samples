Power Pages Server Logic sample

Content Security Policy reporting

This enhanced data model Power Pages site demonstrates browser-generated CSP violation reports delivered to a dedicated anonymous Server Logic endpoint without an antiforgery token.

Configuration

Site setting Value
ServerLogic/SkipCsrfValidationEndpoints csp-report
HTTP/Reporting-Endpoints csp-endpoint="https://example.invalid/_api/serverlogics/csp-report"
HTTP/Content-Security-Policy-Report-Only img-src *; report-to csp-endpoint;

Harmless browser violation

The policy omits data: from img-src, so this image creates a genuine report. The image remains visible because the policy is report-only.

Security Note

CSP reports are anonymous, untrusted input. The receiver limits request body and batch size, accepts only application/reports+json, validates the report type and bounded allowlisted fields, never renders or executes supplied values, and does not persist report content. Only the dedicated csp-report endpoint skips antiforgery validation.
