Supplier Invoice Portal

Plan Overview

Data model architecture for Supplier Invoice Portal

This data model adds the spnvc_purchaseorder table to support the new Phase 2 Purchase Order functionality. The existing invoice tables (spnvc_invoice, spnvc_invoicecomment, spnvc_invoiceattachment) and the spnvc_supplier table are reused as-is. The invoice table is modified to add a lookup from invoices to purchase orders, replacing the current free-text PO Number field with a proper relational link. The standard contact table is reused for user identity.
