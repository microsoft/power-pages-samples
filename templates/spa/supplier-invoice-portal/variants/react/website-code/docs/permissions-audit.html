Audit Summary

CRITICAL: All 13 table permissions on this site have ZERO mspp_entitypermission_webrole associations in Dataverse. The YAML files define adx_entitypermission_webrole references, but this Enhanced Data Model site reads from mspp_entitypermission_webrole at runtime. This means NO permissions are effective -- every Web API call will fail with 403 errors. Additionally, there is a duplicate 'Authenticated Users' web role in mspp_webroles. The permission CRUD flags and scope configurations are correctly defined in the YAML files, but they have no effect until the mspp_ web role associations are created. The user's specific error about contact AppendTo during invoice creation is a direct consequence of this systemic issue.
