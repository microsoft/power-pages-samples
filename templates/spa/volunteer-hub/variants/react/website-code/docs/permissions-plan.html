Volunteer Hub permissions plan

Volunteer Hub is a public, read-only catalog. Its fictional Organization and Opportunity records are intentionally available to anonymous visitors.

Web role

Anonymous Users (0b0eaf51-bf3a-401c-8078-5bed17304f01).

Organization

  • Table: vol_organization
  • Scope: Global
  • Privileges: read only
  • Purpose: direct organization reads and the Opportunity organization expansion.

Opportunity

  • Table: vol_opportunity
  • Scope: Global
  • Privileges: read only
  • Purpose: opportunity list and record reads.

Relationship and fields

Opportunity reads use the case-sensitive vol_OrganizationId expansion. Web API settings enumerate exact fields for both tables. Wildcards and inner-error output are not enabled.

Excluded privileges

Create, write, delete, append, and append-to are intentionally disabled. The portal has no authoring or administrative CRUD flow.
