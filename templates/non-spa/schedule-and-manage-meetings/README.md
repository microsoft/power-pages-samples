# Schedule and Manage Meetings

Schedule and Manage Meetings enables people to quickly schedule appointments with specific staff
members regarding specific topics.

## Capabilities

- Customizable location picker
- Step-by-step forms with customizable sample date
- Custom date-time picker
- Custom calendars
- Automated email notifications for reminders and alerts
- Customizable themes and fonts to match your branding

The site is provisioned by the Power Pages Create Website API. The platform owns the generated
website source and solutions; this directory contains documentation only. Use
[`templates/manifest.json`](../../manifest.json) for the exact API identifier and catalog metadata.

Paired desktop and mobile reference screenshots are available in [`previews/`](previews/).
